## Current State

### What Works ✅
- `!here` creates DM, records attendance, sends Bell Ringer from lesson JSON
- Warm-up context injected into every LLM turn (verified via log: `injected context for @s_aromero (warmup lesson_G8_M1_T1_L1_d1)`)
- Context includes: warmup_id, prompt, TEKS, lesson title, essential question, key terms
- Graceful fallback to hardcoded pool if `current_lesson.json` missing
- Gateway restarts with `--replace` preserve session continuity

### Key Design Finding 🔍
**The TEA slide deck has NO Bell Ringer slide.** Slides start with Learning Objectives → Key Terms → Essential Question. The Bell Ringer is spiral review from prior grades — the `bell_ringer_spiral_suggestions` field in the analysis JSON is the correct source.

### Known Issues 🐛
- Gateway restarts during an active conversation cause confused auto-resumed sessions
- LLM can hallucinate student names ("Leea") when context lacks display name info (mitigated but not eliminated)
- Honcho uploads time out (~30s each for MEMORY.md + USER.md) adding startup latency

## What's Next (When Resumed)

### Phase A: Complete the Warm-Up Pipeline
1. **Content-route more lesson steps** — add `!next`, `!hook`, `!3a`, `!practice`, `!closure` slash commands that load their corresponding sections from `current_lesson.json`
2. **Rotate `current_lesson.json`** — auto-advance daily (cron job to update the pointer)
3. **Bell Ringer variety** — rotate through a small pool within each lesson's spiral review suggestions

### Phase B: Lesson Orchestrator
4. **Team room delivery** — `!next` posts to team rooms, not just DMs
5. **Sequential state** — track which step each team is on (Bell Ringer → Hook → 3A Talk → Practice → Closure)
6. **Response collection** — collect 3A Talk sentence stems, exit tickets into a log

### Phase C: Slide Integration
7. **PPTX text extraction** — `python-pptx` for verbatim TEA slide text (no vision AI needed)
8. **Image routing** — send slide screenshots alongside discussion prompts (limited by model's `image_input_mode`)

### Design Question (Deferred)
**Hook-push vs LLM-present:** Should the hook send Bell Ringer content deterministically (curriculum fidelity) or should the LLM present it conversationally? Current approach is hybrid — hook sends verbatim text, LLM enriches with follow-up discussion. See `references/lesson-content-routing.md` for Claude Code's analysis.
